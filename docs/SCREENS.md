# Knot — Screens

The mobile screen inventory: what exists today, what is planned, and how the concept's
navigation maps onto it. "Shipped" means the screen is implemented in
`apps/mobile/src/screens/` and reachable from the app's state machine. Everything else is
intent, and an entry becomes real only when its task is dispatched (see
[`docs/ENGINEERING_WORKFLOW.md`](ENGINEERING_WORKFLOW.md)).

Phase labels: **Phase 1** — identity, stories, Tell My People. **Phase 2** — Rooted,
Discovery Map, Curious Inquiries, notifications. **Post-MVP** — everything after those.

## Bottom navigation

The app's mobile navigation is a five-destination bottom tab bar with **Create**
raised in the centre (KNOT-ADR-019). KNOT-020j set the final five — Home, Map,
Create, Inquiries, Notifications — and the destinations map onto what exists
today:

| Destination | Concept purpose | Maps to today |
| --- | --- | --- |
| **Home** | The feed of stories and the adaptations of them. | `FeedScreen` (shipped). |
| **Map** | Explore stories and languages by place. | `DiscoveryMapScreen` (shipped), opening `PlaceStoriesScreen` for one place. |
| **Create** (centre) | Publish a story. | `CreateStoryScreen` (shipped). |
| **Inquiries** | Find and ask questions. | `InquiryListScreen` (shipped), opening `InquiryDetailScreen` / `AskInquiryScreen` as overlays (KNOT-ADR-058). |
| **Notifications** | The activity inbox. | `NotificationsScreen` (shipped), with an unread-count badge on the tab (KNOT-020j). |

All five destinations have a shipped screen behind them. Profile is no longer a tab: the
signed-in person's avatar at the right of the Feed header opens the profile overlay
(`UserProfileScreen`, KNOT-020j). Per-version conversations remain
`CommentThreadScreen`, reached from a story rather than from the bar. The bar's own shape is documented in
[`docs/NAVIGATION.md`](NAVIGATION.md).
