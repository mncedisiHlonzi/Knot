# Knot — Design Screens (light and dark)

Open `index.html` in any browser for a gallery of all 22 screens in both themes. Click a screen to open it full size. Each screen is also a standalone file in `light/` and `dark/`, numbered in app-flow order.

Contents
- `light/`, `dark/`: 22 mobile screens each (390 x 844).
- `tokens.json`: colours for both themes, type scale, spacing, radius, elevation and motion values.
- `index.html`: gallery of everything.

Notes
- These are static visual mockups, not production code. Sample names, counts and text are placeholders.
- Fonts (Inter, Plus Jakarta Sans) load from Google Fonts, so open the files online for correct type.
- Not yet drawn: Onboarding slides 2 and 3, the Language, Location and Media pickers, the Report modal, empty/error/offline states.
