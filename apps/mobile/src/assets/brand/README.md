# Knot brand assets

27 SVG files, plus `index.html` (open it in a browser to see everything).

- Logos (7): gradient #6B46FF to #004BFF on the logomark only. The wordmark is outlined paths from Plus Jakarta Sans ExtraBold (SIL OFL), so there is no font substitution and no font dependency.
- App icons (4): 1024 x 1024, corner radius 22%. Logomark is 60% of the icon width. The monochrome icon is on a transparent background.
- Illustrations: splash hero, onboarding hero, four empty states, four Thread frames. Single strokes in #5B35E8, spot fill #E9E4FD.
- Reaction glyphs (5): 24 x 24, 1.5 stroke, round caps, drawn with `currentColor` (default navy) so they can be tinted in the app.
- Rooted mark: 14 x 14, 1.5 stroke, #5B35E8.

Every file has a `<title>`, no embedded images, fonts or scripts, and no text elements.
Check the Rooted mark at its real 14 px size on a device before shipping.
