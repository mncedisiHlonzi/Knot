# Knot

Knot is a multilingual social knowledge and cultural storytelling platform. It ties
human stories, languages, and truths together — a global, visual library in which the
people closest to a place are heard first.

> **Status:** Foundation. This repository currently contains scaffolding, tooling, and
> documentation only. No product features are implemented.
